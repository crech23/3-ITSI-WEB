MÓDULO 3.4 · BTVITSI

Gestión de servicios de red y aplicaciones empresariales

Revisa cómo se conectan los servicios de red y cómo se mantienen disponibles las aplicaciones de una organización.

180 horas6 semanasITSI

¿De qué trata?

Instalar, configurar y mantener servicios de red y aplicaciones empresariales para mejorar la disponibilidad del centro de datos.

Temas principales

Servicios de red para voz y datos

Los servicios de red permiten que los dispositivos y aplicaciones intercambien información dentro de una organización.

Configuración básica de DNS y DHCP

DNS relaciona nombres de equipos con direcciones IP. DHCP asigna automáticamente la configuración de red a los dispositivos.

Conectividad entre equipos y servidores

Se revisan direcciones y conexiones para comprobar que los dispositivos puedan comunicarse con los servidores necesarios.

Respaldo y verificación de las aplicaciones

Respaldar configuraciones y comprobar el funcionamiento de las aplicaciones facilita recuperarlas cuando ocurre un problema.

Una idea para practicar

Armar una red de práctica en Packet Tracer con asignación de direcciones IP, DNS y un servicio web; después, comprobar la conexión.
