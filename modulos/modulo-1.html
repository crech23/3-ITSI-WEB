MÓDULO 3.1 · BTVITSI

Gestión de bases de datos

Aprende a organizar, consultar y cuidar la información que una empresa guarda en sus bases de datos.

180 horas6 semanasITSI

¿De qué trata?

Instalar, configurar, diseñar y mantener bases de datos; también respaldar y recuperar información para que esté disponible y correcta.

Temas principales

Diseño de tablas y relaciones entre datos

Una base de datos organiza la información en tablas. Las relaciones conectan datos relacionados y ayudan a evitar repeticiones.

Consultas SQL para buscar y actualizar información

Con SQL se pueden buscar registros, filtrar resultados y agregar o modificar información según lo que necesite el sistema.

Configuración y mantenimiento de una base de datos

Incluye preparar la base, organizar el acceso de usuarios y revisar que funcione correctamente para mantener la información disponible.

Copias de seguridad y comprobación de integridad

Las copias permiten recuperar información ante un error. También se revisa que los datos estén completos y puedan consultarse.

Una idea para practicar

Diseñar una base de datos pequeña para una biblioteca o un inventario, hacer consultas y demostrar que puede recuperarse desde una copia de seguridad.
